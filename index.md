# Coal Drive Automation

A private-use tool for managing files in an authorized Google Drive account.

Coal Drive Automation connects local file-management workflows to Google Drive through rclone and a dedicated Google OAuth client. It can find, download, upload and organize files when directed by the account owner. It is not a public file-sharing service and does not accept public registrations.

Google authorization controls which account the tool can access. The account owner can revoke that access in their [Google Account permissions](https://myaccount.google.com/connections).

This website contains documentation only. It does not display Drive files, collect Google credentials or provide access to the tool.
